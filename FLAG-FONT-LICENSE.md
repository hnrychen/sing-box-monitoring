# Country flag font attribution

The deployed `TwemojiCountryFlags.woff2` is the flag-only subset distributed by
[TalkJS country-flag-emoji-polyfill 0.1.8](https://github.com/talkjs/country-flag-emoji-polyfill).
It derives from [Mozilla Twemoji COLR](https://github.com/mozilla/twemoji-colr),
using [Twemoji](https://github.com/twitter/twemoji) artwork by Twitter and other
contributors. The subset removes non-flag glyphs; no visual designs were changed
by this repository.

Twemoji artwork is licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
Mozilla's font-building code is licensed under Apache 2.0 and the TalkJS polyfill
code under MIT. See the [Mozilla license](https://github.com/mozilla/twemoji-colr/blob/master/LICENSE.md)
and upstream projects for the complete terms and attribution.

This notice is also served beside the self-hosted font, at
`/public/fonts/FLAG-FONT-LICENSE.md`.
